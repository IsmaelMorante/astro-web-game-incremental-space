# Documentación

## Estructura
- `dev/<rama>/`: un desarrollo por rama de git. Contiene `estado.md`, `requisitos.md`, `plan.md` y `decisiones/`.
- `modulos/<modulo>.md`: una nota por módulo.
- `decisiones/`: decisiones transversales, un fichero por decisión.
- `_export/`: vistas derivadas en Lenguaje de Marcado de Hipertexto (HTML). Git las ignora.

## Cómo recoger un desarrollo
1. Abre `dev/<rama>/estado.md`.
2. Sigue «Cómo continuar».
